# Disney Cruise Line Scraper

Relu Consultancy hiring challenge, Objective 1: extract cruise data from
`https://disneycruise.disney.go.com/en-in/`.

## Files

| File | Description |
|---|---|
| `disney_cruise_scraper.py` | The complete scraper (Steps 1 to 6 plus the five answers) |
| `raw_cards.csv` | Temporary data: every card exactly as scraped (Step 5) |
| `results.csv` | Final cleaned data (Step 6) |
| `answers.txt` | The answers to the five questions (also printed in the terminal) |

Locally (a browser window opens so you can watch the run):

```

```

Without a browser window (headless):

```
HEADLESS=1 python disney_cruise_scraper.py
```

On Linux without a display, such as Google Colab, headless mode is switched on automatically.
A full run opens the site four times (all cruises, then three filtered searches), so it takes several minutes.

## How it works

| Step | What the script does |
|---|---|
| 1. Navigate and agree | Opens the URL and clicks an Agree or Accept button if the site shows one. No banner appeared during development, so the click is optional and the script continues without it. |
| 2. Search | Clicks **View Dates** with no filter, so the full list of cruises is searched. |
| 3. Wait for results | Waits until the first cruise cards are on the page. It waits for the card element and does not use a fixed pause. |
| 4. Collect data | The site loads cards as you scroll (infinite scroll, no page numbers). The script scrolls until no new cards appear for five attempts in a row, then reads every card. |
| 5. Clean | Saves `raw_cards.csv`, then trims text, removes rows with empty fields (locations must be present), removes duplicates and checks that no empty cell is left. |
| 6. Store | Saves the cleaned data to `results.csv`. |

Robustness: explicit waits for page elements, a retry (up to 3 attempts) around each search, and a safety limit on scrolling.
A card that fails to read is skipped with a message and does not stop the run.

### Columns in `results.csv`

| Column | Content |
|---|---|
| `title` | Card heading, for example "4-Night Bermuda Cruise from New York" |
| `departure_port` | Text after "from" in the title |
| `departure_city` | Departure port without "ending in ..." or "with ... stops" (used for Question 5) |
| `sailing_to` | Ports listed under "Sailing to"; several ports are joined with ` | ` |
| `price` | Price text as shown on the card |
| `currency` | Currency text as shown on the card (INR) |
| `num_dates` | Number taken from the "Show N Dates" button |
| `dates_button` | The button text as shown on the card |

## Cleaning rules

1. Trim leading and trailing spaces and collapse repeated spaces and line breaks.
2. Treat empty text as missing.
3. Remove any row with an empty required field: `title`, `departure_port`, `sailing_to`, `price`, `currency`, `num_dates`. This enforces "locations must not be empty".
4. Remove exact duplicate rows. Rows are not de-duplicated on the title alone, because many different cruises share a title (for example "3-Night Baja Cruise from San Diego" with different ports, prices and dates).
5. Check that the final file has no empty cells.

## Important notes about the data

- **The website counts sailing dates, not cards.** The number shown above the results (for example "949 Cruises") is the sum of the "Show N Dates" values across all cards. One card is one itinerary and can have many dates. For example, the Pacific Coast filter shows "5 Cruises", but it is 2 cards with 3 and 2 dates. The script treats one card as one cruise, and the reference section of the output also prints the website's own counts.
- **Two cards were removed in cleaning.** The "3-Night Cruise from Singapore" and "4-Night Cruise from Singapore" cards have no ports under "Sailing to", so they are removed by the rule that locations must be present. This changes the answers to Questions 2 and 4 by 2 each (see below).
- **Number of pages.** The site has no page numbers. The script keeps scrolling until the list ends, so the complete list is collected (170 cards at the time of the run, 168 after cleaning). The scroll progress is printed so the batches can be checked.
- **The site's data changes over time.** Counts can differ slightly on other days, so run the script again for the final numbers.

## Answers to the five questions

Values from the run on 4 October 2026. The script prints the current values each time it runs.

| # | Question | How it is calculated | Answer |
|---|---|---|---|
| 1 | Total cruises for the Pacific as a destination | Cards returned by the **Pacific Coast Cruises** destination filter (cross-check: cards with "Pacific" in the title) | 2 (the website shows 5 because it counts dates) |
| 2 | Total cruises | Rows in `results.csv` | 168 (170 before the two Singapore cards were removed; the website shows 949 sailing dates) |
| 3 | Holiday cruises | Unique cards returned by the **Halloween on the High Seas** and **Very Merrytime** filters, counted once if they appear in both | 71 (all 27 Halloween cards are also in the Very Merrytime list) |
| 4 | Cruises offering more than 2 dates | Rows with `num_dates` greater than 2 | 65 (67 before removing the two Singapore cards) |
| 5 | Cruises with Miami and London as departure ports | Rows whose `departure_city` contains Miami or London | 0 (Miami: 0, London: 0) |

The Marvel Days at Sea and Pixar Days at Sea options are themed cruises and are not counted as holiday cruises.
